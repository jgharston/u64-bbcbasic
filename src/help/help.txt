# Topics

@@ BBC | COMPATIBILITY
BBC BASIC programs run: the BBC BASIC 3.10 language and the behaviour of the VDU, graphics, sound and file statements.

This is not a BBC Micro emulator. The BBC memory map (screen memory, MODE 7 teletext), the BBC hardware at &FE00, the MOS internals and BBC machine code are not there. Programs that poke the machine, or CALL machine code written for the BBC, do not work.

The MOS calls a program can use are those in *HELP OSBYTE, *HELP OSWORD and *HELP MEMORY.

@@ KEYBOARD
Letters type in capitals, as with CAPS LOCK on a BBC Micro. Shift gives lower case.

The ASCII characters the C64 keyboard lacks:

  \  pound key       ^  up-arrow
  _  left-arrow      |  Shift+pound
  ~  Shift+up-arrow  {  Shift++
  }  Shift+-         `  Shift+@

RUN/STOP is ESCAPE: it stops a program or a listing. RESTORE also sets ESCAPE.

Lines are edited with the C64 screen editor: move the cursor anywhere and press RETURN to enter a line again. A line can be up to 78 characters after the prompt.

GET and INKEY return the cursor keys as 136-139 (left, right, down, up), DEL as 127 and CLR as 12.

@@ MEMORY
Memory map while BASIC runs:

  &0000-&0051  BASIC zero page
  &0052-&006F  MOS zero page
  &0070-&008F  free for machine code
  &0090-&00FF  C64 KERNAL
  &0100-&01FF  6502 stack
  &0200-&021F  BBC MOS vectors
  &02A7-&02FF  MOS error buffer
  &033C-&03FB  MOS variables
  &0400-&07FF  BASIC workspace
  &0800-&18FF  sound engine
  &1900-&7FFF  program (PAGE-HIMEM)
  &8000-&BFFF  BBC BASIC (RAM copy)
  &C000-&C3FF  screen / colours
  &C400-&C7FF  resident MOS
  &C800-&CFFF  VDU core
  &D000-&DFFF  I/O, graphics below
  &E000-&FFFF  KERNAL, bitmap below

PAGE is &1900 (as on a BBC Micro with discs) and HIMEM &8000: 26.75K for programs. Some modes need RAM below HIMEM: MODE 7 keeps its screen at &7C00, the Upic Lite modes their picture at &5800 (MODE 0, 3, 4, 5, 6) or &3000 (MODE 1, 2); HIMEM is lowered to match, as on a BBC Micro. Under the I/O area is the drawing engine, under the KERNAL the bitmap (&E000) and the text font (&F000). The area &70-&8F is free for your own machine code, as on a BBC Micro.

BASIC runs from RAM because the Ultimate 64 reads cartridge ROM at 1 MHz even in turbo mode.

*MEMORY shows the map of the running program; *MEMORY UPIC OFF (or *SHADOW) keeps HIMEM at &8000 in every mode but MODE 7.

@@ FILES
Files are kept on the Ultimate's own storage: USB sticks (/Usb0, /Usb1), the SD card (/SD) and the RAM disk (/Temp, gone after power off). Names are Ultimate paths, relative to the current directory.

  *DIR /Usb0/bbc    choose a directory
  *CAT              list it
  SAVE "game"       save the program
  LOAD "game"       load it again
  CHAIN "game"      load and run

Two files can be open at the same time (channels &11 and &12): OPENIN, OPENOUT, OPENUP, BGET#, BPUT#, PRINT#, INPUT#, PTR#, EXT#, EOF#, CLOSE#.

Programs are saved in the BBC's tokenised format, so programs from BBC Micro disc images can be loaded once extracted to a file.

See also: *CAT, *DIR, *LOAD, *SAVE, *TYPE, *DELETE, *RENAME, *MKDIR.

@@ ULTIMATE
U64 BBC BASIC uses the Ultimate's command interface (UCI) for files, the clock and identification, and the U64 turbo registers for speed.

  *UVER    firmware targets
  *TIME    date and time
  *TURBO   CPU speed
  *CAT     files (see FILES)

The cartridge's .cfg file switches on everything needed when the cartridge is started from the Ultimate's file browser: Command Interface, REU, Ultimate Audio and the U64 turbo registers.

Planned: drives and disk images, REU, network, Ultimate Audio, Upic graphics, palette.

@@ ERRORS
An error stops the program and prints a message; ON ERROR catches it. ERR gives the error number, ERL the line, REPORT prints the message.

Errors from the Ultimate keep the Ultimate's text with these numbers:

  214  file not found
  189  access denied
  192  too many open files
  199  other Ultimate errors
  198  no room (LOAD too big)
  222  channel not open
  254  bad command
  252  bad number

@@ OPERATORS
Arithmetic: + - * / ^ (power), DIV and MOD (integers). Comparison: = <> < > <= >=, giving TRUE (-1) or FALSE (0). Logical/bitwise: AND OR EOR NOT.

Indirection reads and writes memory:

  ?A       byte at address A
  !A       4-byte integer at A
  $A       string at A (CR ended)
  A?2      byte at A+2
  A!4      integer at A+4

Example:

  DIM B% 10:?B%=65:PRINT ?B%

Hexadecimal: &FF is 255; PRINT ~X prints X in hexadecimal.

@@ VARIABLES
Names are letters, digits and _ and may be long. Types by suffix:

  A    real (5 bytes, ~9 digits)
  A%   integer (32 bits)
  A$   string (up to 255 chars)

The integers @% and A% to Z% are resident: they survive RUN, NEW and CLEAR. @% sets the PRINT format; A%, X%, Y% and C% pass registers to CALL and USR.

Arrays: DIM A(10), DIM N$(5,5). Strings keep their space when a new value fits. Space that strings give up is only reclaimed by CLEAR or RUN.

@@ ASSEMBLER
BBC BASIC contains a 6502 assembler. Square brackets enclose assembly language; P% is the address to assemble at; OPT sets listing and errors.

  10 DIM C% 20
  20 FOR Z%=0 TO 2 STEP 2
  30 P%=C%:[OPT Z%
  40 LDA #65:JSR &C7EE:RTS
  50 ]:NEXT
  60 CALL C%

OPT 0 assembles silently; OPT 2 reports errors; add 1 to list. Two passes resolve forward references. Labels start with a dot.

U64: OSWRCH is &C7EE, not &FFEE (see *HELP MOS). Zero page &70-&8F is free for your code.

@@ MOS
The MOS (machine operating system) entry points, at BBC Micro low bytes in page &C7:

  OSFIND &C7CE   OSGBPB &C7D1
  OSBPUT &C7D4   OSBGET &C7D7
  OSARGS &C7DA   OSFILE &C7DD
  OSRDCH &C7E0   OSASCI &C7E3
  OSNEWL &C7E7   OSWRCH &C7EE
  OSWORD &C7F1   OSBYTE &C7F4
  OSCLI  &C7F7

The RAM vectors are at &0200-&021F as on a BBC Micro (BRKV &0202, WRCHV &020E, ...). See OSBYTE, OSWORD and VDUCODES.

@@ OSBYTE
OSBYTE calls (*FX a,x,y) available:

  &00   OS version (X=1)
  &0F   flush keyboard buffer
  &15   flush keyboard buffer
  &72   shadow for next MODE
  &75   VDU status (4: shadow)
  &7C   clear ESCAPE
  &7D   set ESCAPE
  &7E   acknowledge ESCAPE
  &7F   EOF# of channel X
  &81   INKEY
  &82   high address (&FFFF)
  &83   OSHWM / PAGE (&1900)
  &84   HIMEM of the mode
  &85   HIMEM for a mode
  &86   POS (X) and VPOS (Y)
  &87   character at cursor
  &DA   VDU queue length
  &E5   ESCAPE key off (X<>0)

Other calls are ignored.

@@ OSWORD
OSWORD calls available: 0 reads a line (screen editor), 1 reads TIME, 2 sets TIME (5 bytes, centiseconds), 9 reads a pixel (POINT), 10 reads a character definition (block +0 = character; +1 to +8 = rows), 14 reads the Ultimate's clock. Others are ignored.

OSWORD 14 as on a BBC Master: put 0 in the first byte of a 25-byte block for the text "Wed,07 Oct 2026.08:42:55" and a CR, or 1 for 7 BCD bytes: year (2 digits), month, day, day of week (1 = Sunday), hour, minute, second.

  DIM B% 25:?B%=0:A%=14
  X%=B% MOD 256:Y%=B% DIV 256
  CALL &C7F1:PRINT $B%

@@ VDUCODES
VDU codes work as on a BBC Micro:

  4     text at the text cursor
  5     text at the graphics cursor
  7     bell (SOUND &13,-15,101,6)
  8-11  cursor left/right/down/up
  12    clear the text window (CLS)
  13    start of line
  16    clear the graphics window (CLG)
  17,n  COLOUR n
  18,a,n  GCOL a,n
  19,l,p,0,0,0  colour l shows colour p
  19,l,16,r,g,b  colour l as RGB
  20    default colours and palette
  22,n  MODE n
  23,1,n  cursor off (0) / on (1)
  23,11  default ECF patterns
  23,12-15  define ECF pattern 1-4
  23,c,8 rows  define character c
  24,l;b;r;t;  graphics window
  25,k,x;y;  PLOT k,x,y
  26    default windows
  28,l,b,r,t  text window
  29,x;y;  graphics origin
  30    cursor home
  31,x,y  TAB(x,y)
  127   delete

Windows, the graphics codes and the palette act in the graphics modes (MODE 0, 1, 2, 4, 5, 103, 104); in text modes 12, 17 and 22 act.

VDU 23,c,r1,...,r8 (c = 32-255) defines a character: 8 rows, top first, bit 7 left. The text screen shows codes 32-127; graphics modes show all of them with an REU (the Ultimates; kept over MODE changes). MODE 7 keeps its teletext glyphs. OSWORD 10 reads a definition.
@@ COLOURS
COLOUR n sets the text colour, COLOUR 128+n the background. BBC colour numbers map to C64 colours:

  0 black    1 red      2 green
  3 yellow   4 blue     5 magenta
  6 cyan     7 white    8 orange
  9 brown    10 light red
  11 dark grey  12 grey
  13 light green  14 light blue
  15 light grey

@@ SPEED
On an Ultimate 64 or C64 Ultimate with the U64 turbo registers enabled, BBC BASIC starts at the highest speed of the machine: 48 MHz (Ultimate 64, Elite) or 64 MHz (Elite II, C64 Ultimate). That is 25 to 30 times a BBC Micro.

TIME stays in real time at every speed. *TURBO shows or changes the speed. On an Ultimate II+ or a plain C64 the speed is 1 MHz.

@@ LIMITS
Things that differ from a BBC Micro in this version:

Typed lines: 78 characters (C64 screen editor); programs sent from a PC (see REMOTE) may have lines up to 251 characters. Graphics: points, lines, triangles, rectangles, parallelograms, circles, ellipses, pattern fills, flood fill, arcs, segments, sectors. Sound: SOUND and ENVELOPE as on a BBC Micro. LOAD and SAVE work between &1900 and &7FFF. Two files open at a time. *KEY, *EXEC and *SPOOL are not there yet.

@@ REMOTE
Programs can be written on a PC and run here: the MOS has a mailbox that a PC (or an AI coding agent) reaches through the Ultimate's network API. At the > prompt the MOS accepts lines and programs from it as if typed, and copies the output back.

  tools/u64remote.py run prog.bas
  tools/u64remote.py exec "PRINT 6*7"

AI agents use the same through the MCP server tools/u64mcp.py. Nothing changes for the user at the keyboard. See docs/REMOTE_DEV.md and docs/AI_AGENTS.md.

@@ DEBUG
Programs sent from a PC can be debugged there: breakpoints, single steps and a view of the variables (VS Code: F5; command line: tools/u64remote.py debug; AI agents: bbc_debug).

It uses TRACE: BASIC reports each line before it runs and the MOS pauses at a breakpoint. The line after a FOR or REPEAT is reported only on the first pass (NEXT and UNTIL jump back into the loop line), so for later passes put the breakpoint on the NEXT or UNTIL line. See REMOTE.

# ---------------------------------------------------------------------------
# * commands

@@ *CAT | CAT | *.
  *CAT     (also *.)

Lists the current directory: the path, then the files in two columns. Directories end in /. ESCAPE stops the listing.

@@ *DIR | DIR | *CD | CD
  *DIR <path>     (also *CD)
  *DIR ~

Changes the current directory. Paths are Ultimate paths: /Usb0/bbc, /SD, /Temp, .. for the parent; ~ is the Ultimate's home directory (User Interface settings).

  *DIR /Temp
  *DIR ..

@@ *PWD | PWD
  *PWD

Prints the current directory.

@@ *MOUNT | MOUNT
  *MOUNT <image> [A|B|<device>]

Mounts a disk image (D64, D71, D81, G64 ...) on one of the Ultimate's drives, drive A if none is given.

  *MOUNT /USB0/games/elite.d64
  *MOUNT disk2.d64 B

@@ *UNMOUNT | UNMOUNT
  *UNMOUNT [A|B|<device>]

Removes the disk image from a drive (drive A if none is given).

@@ *SWAP | SWAP
  *SWAP [A|B|<device>]

Moves a drive (drive A if none is given) on to the next disk of its disk set, as the Ultimate's swap function does for multi-disk games.

@@ *DRIVE | DRIVE
  *DRIVE A|B ON|OFF

Switches one of the Ultimate's drives on or off.

@@ *COPY | COPY
  *COPY <file> <directory>

Copies a file into another directory on the Ultimate's storage, under the same name. An existing file there is not overwritten (error "File exists").

  *COPY game /USB0/backup

@@ *SETTIME | SETTIME
  *SETTIME yyyy/mm/dd hh:mm:ss

Sets the Ultimate's clock. The Ultimate's settings can forbid this (error "Function prohibited").

@@ *PARTITION | PARTITION
  *PARTITION <n> <path> [<name>]
  *PARTITION <n> OFF

Makes partition n of the Ultimate's SoftIEC drive point to a directory. From firmware 3.15 the SoftIEC drive reaches files only through partitions; without one it serves /Temp. OFF removes a partition (not effective on firmware 3.15a).

  *PARTITION 3 /USB0/c64 GAMES
  *CP 3

@@ *PARTITIONS | PARTITIONS
  *PARTITIONS

Lists the SoftIEC drive's partitions (its "$=P" directory).

@@ *CP | CP
  *CP <n>

Selects partition n on the SoftIEC drive (the drive's own CP command).

@@ *DELETE
  *DELETE <name>

Deletes a file.

@@ *MKDIR | MKDIR | *CDIR | CDIR
  *MKDIR <name>   (also *CDIR)

Creates a directory.

@@ *RENAME | RENAME
  *RENAME <old> <new>

Renames a file.

@@ *LOAD
  *LOAD <name> <address>

Loads a file into memory at an address (decimal or &hex), between &0800 and &7FFF.

  *LOAD screen &3000

@@ *SAVE
  *SAVE <name> <start> <end>
  *SAVE <name> <start> +<length>

Saves memory to a file. The end address is not saved. Memory up to &7FFF can be saved.

  *SAVE code &3000 +&200

@@ *TYPE | TYPE
  *TYPE <name>

Prints a text file. Lines end in CR; LF and other control codes are skipped. ESCAPE stops.

@@ *UVER | UVER
  *UVER

Shows the identification of the Ultimate's DOS and control targets.

@@ *TIME
  *TIME

Prints the date and time of the Ultimate's clock. The BASIC variable TIME is a separate centisecond counter.

@@ *TURBO | TURBO
  *TURBO          show the speed index
  *TURBO MAX      fastest (index 15)
  *TURBO OFF      1 MHz (index 0)
  *TURBO <n>      speed index 0-15

Needs the U64 turbo registers (Turbo Control in the Ultimate's settings, switched on by the cartridge's .cfg). Index 15 is 48 MHz on an Ultimate 64 and 64 MHz on an Elite II or C64 Ultimate. See SPEED.

@@ *FONT | FONT
  *FONT LOAD <file> [fmt]  load
  *FONT SAVE <file> [fmt]  save
  *FONT BBC      BBC Micro characters
  *FONT C64      C64 character ROM
  *FONT DEFAULT  the start-up font
fmt: C64 (default), BBC or ASCII.

C64 is a C64 charset: 2048 bytes in screen-code order (2050 with a load address also loads). BBC is 768 bytes, characters 32-127 in ASCII order, as in a BBC Micro MOS ROM at &C000. ASCII is 2048 bytes, characters 0-255 in ASCII order.

With an REU (the Ultimates) the font shows on the text screen and in the graphics modes and stays over MODE changes. Without one only the text screen changes. MODE 7 builds its teletext glyphs from the font when it starts. VDU 23 changes single characters. The BBC characters are Acorn's (see CREDITS).

@@ *MEMORY
  *MEMORY            memory map
  *MEMORY UPIC OFF   VIC-II modes
  *MEMORY UPIC ON    Upic Lite
  *MEMORY UPIC AUTO  (as ON)

Shows PAGE, TOP, LOMEM, VARTOP, HIMEM, free memory and where the screen is.

On a 64 MHz Ultimate the BBC modes 0-6 use Upic Lite: exact 320x256 like a BBC Micro, with the picture below HIMEM (&5800 or &3000), as on the BBC. UPIC OFF makes the next MODE use the VIC-II version instead: 200 lines, but HIMEM stays &8000. The same as *SHADOW. MODE 7 always keeps its screen at &7C00.

@@ *SHADOW | SHADOW
  *SHADOW     shadow modes
  *SHADOW 1   normal modes

As on a BBC Master: from the next MODE on, a shadow mode keeps the screen out of BASIC's memory, so HIMEM stays &8000. Here that is the VIC-II version of the mode instead of Upic Lite. MODE 128+n is shadow for that mode only. OSBYTE &72 does the same from a program (X = 0 shadow, 1 normal), OSBYTE &75 bit 4 says whether the current mode is one. See *MEMORY.

@@ *PALETTE | PALETTE
  *PALETTE LOAD <file> [VPL]
  *PALETTE SAVE <file>
  *PALETTE BBC    BBC's pure colours
  *PALETTE C64    Ultimate's defaults
  *PALETTE RESET  palette at start-up

The RGB colours of the 16 C64 colours, as the Ultimate shows them. Files are 48 bytes (red, green, blue per colour, in C64 colour order); with VPL a VICE palette file. BBC gives the 8 C64 colours the BBC colours use the BBC's pure red, green, ... The start-up palette is the one chosen in the Ultimate's menu.

VDU 19,l,16,r,g,b sets logical colour l to an RGB colour (0-255 each): in Upic Lite modes that colour only, elsewhere the C64 colour l shows.

Needs firmware 3.15a or later; all but C64 need an REU. Upic Lite and MODE 7 use the palette for their own picture and keep it until the next MODE change.

@@ *SID | SID
  *SID               list the SIDs
  *SID PAN <unit> <p>     stereo
  *SID VOL <unit> <dB>    volume

The SIDs found at start-up: up to 8, at &D400-&D7E0. The cartridge's .cfg sets up 8 UltiSIDs (two UltiSIDs split four ways, as Heartbeat Soundtracker does) and switches them on, UltiSID 1 left and UltiSID 2 right.

unit: 1 or 2 (UltiSID 1 or 2; with the .cfg the 1st, 3rd, 5th and 7th SID are UltiSID 1's) or S1, S2 (the SID sockets). p: -5 (left) to 5 (right), 0 centre. dB: -42 to 6 (the Ultimate's steps), or OFF. The setting takes effect at once and lasts until the Ultimate is reset. Needs firmware 3.15a.

@@ *STATUS | STATUS | *SYS | SYS
  *STATUS     (also *SYS)

Shows the system: MOS and cartridge, the Ultimate's hardware, CPU speed, REU size, BASIC's memory (PAGE, TOP, LOMEM, VARTOP, HIMEM, free bytes), open files, the current directory, the drives, the network address and the clock.

@@ *FX | FX
  *FX a[,x[,y]]

Calls OSBYTE a with X=x and Y=y. See OSBYTE.

  *FX 15     flush the keyboard buffer

@@ *HELP
  *HELP [subject]

Shows help: see HELP.

# BASIC keywords (BBC BASIC 3.10)

@@ ABS
  ABS(n)

The absolute value of n.

  PRINT ABS(-3.5)   gives 3.5

@@ ACS
  ACS(n)

Arc cosine of n, in radians.

@@ ADVAL
  ADVAL(n)

ADVAL(-5) to ADVAL(-8): free room in the sound queue of channel 0 to 3, as on a BBC Micro: 15 when empty, 4 bytes per note waiting. Other values return 0 (no analogue port).

@@ AND
  a AND b

Bitwise AND of two integers; with comparisons a logical AND.

  IF X>0 AND X<10 PRINT "OK"

@@ ASC
  ASC(s$)

ASCII code of the first character of s$; -1 for an empty string.

@@ ASN
  ASN(n)

Arc sine of n, in radians.

@@ ATN
  ATN(n)

Arc tangent of n, in radians.

@@ AUTO
  AUTO [start[,step]]

Numbers new lines automatically, from 10 in steps of 10 by default. ESCAPE stops.

@@ BGET# | BGET
  b=BGET#c

Reads one byte from channel c. See FILES.

@@ BPUT# | BPUT
  BPUT#c,b

Writes byte b to channel c.

@@ CALL
  CALL address[,params]

Calls machine code. A, X, Y and the carry come from A%, X%, Y% and C%.

@@ CHAIN
  CHAIN "name"

Loads and runs a program.

@@ CHR$
  CHR$(n)

The character with code n.

  PRINT CHR$(65)    gives A

@@ CLEAR
  CLEAR

Removes all variables except the resident integers @% and A%-Z%.

@@ CLG
  CLG

Clears the graphics window in the background colour (GCOL 0,128+n).

@@ CLOSE# | CLOSE
  CLOSE#c

Closes channel c; CLOSE#0 closes all channels.

@@ CLS
  CLS

Clears the text screen.

@@ COLOUR | COLOR
  COLOUR n

Sets the text colour (n) or background (128+n). See COLOURS.

@@ COS
  COS(r)

Cosine of r radians.

@@ COUNT
  COUNT

The number of characters printed since the last new line.

@@ DATA
  DATA item[,item...]

Values for READ. See READ, RESTORE.

@@ DEF
  DEF PROCname[(params)]
  DEF FNname[(params)]=expr

Defines a procedure or function. See PROC, FN.

@@ DEG
  DEG(r)

Converts radians to degrees.

@@ DELETE
  DELETE first,last

Deletes program lines first to last.

@@ DIM
  DIM A(n), B$(x,y)
  DIM P% n

Declares arrays, or reserves n+1 bytes of memory and puts the address in P%.

@@ DIV
  a DIV b

Integer division.

  PRINT 7 DIV 2    gives 3

@@ DRAW
  DRAW x,y

Draws a line from the graphics cursor to x,y in the graphics colour (PLOT 5,x,y). Coordinates: 1280 x 1024, 0,0 at the bottom left, as on the BBC.

@@ ELSE
  IF cond THEN a ELSE b

The part of an IF line run when the condition is false. Also after ON ... GOTO.

@@ END
  END

Ends the program.

@@ ENDPROC
  ENDPROC

Ends a procedure. See PROC.

@@ ENVELOPE
  ENVELOPE n,t,pi1,pi2,pi3,pn1,pn2,pn3,
           aa,ad,as,ar,ala,ald

Defines envelope n (1-16), as on a BBC Micro. t: step length in 1/100 s (add 128: the pitch part does not repeat). pi1-pi3: pitch change per step in three sections of pn1-pn3 steps. aa, ad: amplitude change per step in the attack and decay, up to the levels ala and ald (0-126); as: change per step while the note lasts; ar: in the release, down to 0. Use it with SOUND c,n,p,d.

@@ EOF# | EOF
  EOF#c

TRUE at the end of the file on channel c.

@@ EOR
  a EOR b

Bitwise exclusive OR.

@@ ERL
  ERL

The line number of the last error.

@@ ERR
  ERR

The number of the last error. See ERRORS.

@@ ERROR
  ON ERROR statements
  ON ERROR OFF

Statements to run when an error occurs. See ERRORS.

@@ EVAL
  EVAL(s$)

Evaluates the expression in s$.

  PRINT EVAL("2*21")   gives 42

@@ EXP
  EXP(n)

e to the power n.

@@ EXT# | EXT
  EXT#c

The length of the file on channel c.

@@ FALSE
  FALSE

The value 0.

@@ FN
  DEF FNname(params)=expr
  x=FNname(args)

A user-defined function; multi-line functions end with =value.

  DEF FNsq(x)=x*x
  PRINT FNsq(7)

@@ FOR
  FOR v=start TO end [STEP s]
  ...
  NEXT [v]

Repeats the statements with v counting from start to end.

@@ GCOL
  GCOL action,colour

Sets the graphics colour and how it is drawn: action 0 store, 1 OR, 2 AND, 3 EOR, 4 invert. Colour 128+n sets the background (CLG).

Pattern fill (ECF, as on the BBC Master): action + 16 * n uses pattern n (1-4) instead of the colour, for everything drawn. VDU 23,12+n-1,c1,...,c8 defines pattern n as 2x4 pixels of logical colours (row by row); VDU 23,11,0;0;0;0; restores the default patterns.

  GCOL 0,1:DRAW 1279,1023
  GCOL 16,0:PLOT 157,640,512

@@ GET
  k=GET

Waits for a key and returns its code. See KEYBOARD.

@@ GET$
  k$=GET$

Waits for a key and returns it as a string.

@@ GOSUB
  GOSUB line

Calls the subroutine at line; RETURN comes back.

@@ GOTO
  GOTO line

Continues at line.

@@ HIMEM
  HIMEM

The top of BASIC's memory (&8000).

@@ IF
  IF cond [THEN] stmts [ELSE stmts]

Runs the statements when the condition is TRUE (not 0). The whole IF is one line.

@@ MODE
  MODE n

Selects a screen mode and clears it.

  MODE size     col text  U64
  0    640x256  2   80x32 Upic Lite
  1    320x256  4   40x32 Upic Lite
  2    160x256  16  20x32 Upic Lite
  3    text         80x25 Upic Lite
  4    320x256  2   40x32 Upic Lite
  5    160x256  4   20x32 Upic Lite
  6    text         40x25 Upic Lite
  7    teletext     40x25 VIC-II
  100  C64 text     40x25
  103  320x200  16  40x25 hires
  104  160x200  16  20x25 multicol.

MODE 7 is teletext, as on the BBC: screen memory at &7C00 (HIMEM &7C00), colour codes 129-135 (text) and 145-151 (mosaic graphics), 141 double height, 154 separated graphics, 157 new background, 156 black background, 158 hold graphics, 136 flashing. Writing to &7C00 directly (?&7C00=...) shows within a few frames. The machine starts in the C64 text screen with its full-screen editor; MODE 100 returns to it.

MODE 0 shows 320 pixels wide. MODE 3 and 6 use rows of 10 lines (250 lines), as on the BBC; without Upic Lite they are the 40x25 text screen. MODE 103: 2 colours per 8x8 cell, MODE 104: 4 per 4x8 cell, as the VIC-II does.

Upic Lite: a live picture of 320x256 (MODE 2 and 5: 160x256 with double-width pixels, 16 or 4 colours anywhere) with square pixels, as on the BBC, on 64 MHz machines (Ultimate 64 Elite II, C64 Ultimate) with firmware 3.15+. The screen memory lies below HIMEM as on the BBC (MODE 0, 3, 4, 5, 6: &5800; MODE 1 and 2: &3000), and BASIC runs at about 1/6 of its speed while the picture is shown. Elsewhere these modes use the VIC-II (200 lines, 32 rows of 6-line text).

@@ PLOT
  PLOT k,x,y

Graphics plotting, as on the BBC: k AND 3 = 0 moves, 1 draws in the graphics colour, 2 inverts, 3 draws in the background colour; k AND 4 = 0: x,y relative to the graphics cursor.

  k 0-7     line
  k 8-15    line, no end point
  k 16-31   dotted line
  k 32-63   line, no start point
  k 64-71   point
  k 80-87   filled triangle
  k 96-103  filled rectangle
  k 112-119 filled parallelogram
  k 128-135 flood fill (background)
  k 136-143 flood fill to foreground
  k 144-151 circle
  k 152-159 filled circle
  k 160-167 arc
  k 168-175 segment
  k 176-183 sector
  k 192-199 ellipse
  k 200-207 filled ellipse
  k 216-223 rectangle (U64)
  k 224-231 triangle (U64)
  k 240-247 parallelogram (U64)

Triangles use the last three points; a rectangle's corners are the previous point and x,y; a parallelogram's fourth corner is worked out as on the BBC. Circles: the centre is the previous point, x,y a point on the circle (PLOT 153,r,0 after MOVE cx,cy). Ellipses: centre, then a point at the end of the horizontal axis, then x,y gives the height. The (U64) outline codes are extensions; the BBC has no outline triangle, rectangle or parallelogram. Flood fill 128-135 fills the background-coloured area around x,y; 136-143 fills up to the foreground colour. Arcs, segments and sectors: the centre is the point two plots back, the previous point gives the radius and the start, x,y the end direction; drawn anticlockwise.

@@ SOUND
  SOUND c,a,p,d

Queues a note, as on a BBC Micro. c = &HSFN: N channel (0 noise, 1-3 tone), F=1 flush the queue first, S sync with S other channels (they start together), H=1 hold (the previous note's release goes on). a: -15 (loud) to 0, or envelope 1-16. p: pitch, 4 steps per semitone, 53 = middle C, 89 = A 440 Hz; channel 0: 0-2 periodic noise, 4-6 white noise (high to low), 3 and 7 at channel 1's pitch. d: 1/20 s, 255 or -1 for ever.

Plays on the SIDs: channels 1-3 on SID 1, channel 0 on the second SID (or with one SID, on channel 3's voice while it plays). Three notes wait per channel; see ADVAL. The extended SID mode with all voices of up to 8 SIDs comes next.
