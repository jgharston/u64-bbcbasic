# U64 BBC BASIC -- user manual

BBC BASIC 3.10 for the Ultimate 64 and the C64 Ultimate, as a cartridge.
One file per chapter; the quick reference on the machine itself is
`*HELP` (all of it in [HELP_REFERENCE.md](../HELP_REFERENCE.md)).

| Chapter | Contents | State |
|---|---|---|
| 1. Introduction | what it is; differences from a BBC Micro | to write |
| 2. Installation | the cartridges, the Ultimate's settings, `make deploy` | to write |
| 3. Building from source | tools, `make`, the tests | to write |
| 4. Starting | start-up, a first program, SAVE and LOAD | to write |
| [5. Typing and editing lines](05_SCREEN_EDITOR.md) | the line editor, history, copy editing, `*EDIT` | written |
| 6. BASIC keywords | the syntax of every keyword | to write |
| 7. Files | the filing system: files and channels, `*CAT`, `*DIR`, the /REU RAM disk | to write |
| 8. Graphics | MODE, VDU, PLOT, colours, fonts, palettes, teletext | to write |
| 9. Sound | SOUND, ENVELOPE, `*SOUND`, `*INSTRUMENT`, `*SONG`, `*SID` | to write |
| 10. Network | `*NET`, `*JSON`, TCP and HTTP channels | to write |
| 11. Ultimate commands | `*TURBO`, `*MOUNT`, `*DRIVE`, the clock | to write |
| 12. Memory | memory map and memory handling: PAGE, HIMEM, modes, the REU, `*MEMORY` | to write |
| 13. MOS calls | OSBYTE, OSWORD, vectors, machine code | to write |
| 14. Developing from a PC | VS Code, `tools/u64remote.py`, the MCP server | to write |
| 15. Errors and limits | error messages, what this BASIC cannot do | to write |

Tutorials (learning to program with the example programs) are planned as
a separate set, `docs/tutorial/`, after this manual.
