# 8. Graphics

The BBC Micro's screen modes 0-7 (80-column modes as their 40-column
twins), drawn with the BBC's coordinates (1280 x 1024, 0,0 at the bottom
left); on a 64 MHz Ultimate as Upic Lite pictures with square pixels and
256 lines, elsewhere with the VIC-II. MODE 7 is teletext, MODE 100 the
C64's text screen, MODE 103 and 104 the C64's own bitmap modes.

## 8.1 Screen modes

@@help MODE *SHADOW

## 8.2 Drawing

@@help CLG GCOL MOVE DRAW PLOT POINT

## 8.3 VDU codes

@@help VDU VDUCODES

## 8.4 Colours, palettes and fonts
