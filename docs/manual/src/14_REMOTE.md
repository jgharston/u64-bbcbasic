# 14. Developing from a PC

Programs can be written on a PC and run on the machine over the
network: with the VS Code extension (`vscode/`, Ctrl+F5 runs the file),
with `tools/u64remote.py` on the command line, or by an AI coding agent
through the MCP server `tools/u64mcp.py` (docs/AI_AGENTS.md). A line
sent from the PC drops a half-typed line on the machine (chapter 5).
